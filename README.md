# Overview

The purpose of this project is to develop a console-based expense management application while strengthening my understanding of the Java programming language and object-oriented programming concepts.

The software is a Java Expense Tracker that allows users to add, view, and delete expenses, calculate total expenses, show expenses by category, and save and load expenses from a file. The application uses an Expense class to represent individual expenses and an ArrayList to store and manage multiple expenses. It also uses file input and output to save expenses to a file and load them when needed.

I developed this software to gain practical experience with Java syntax and programming concepts such as variables, conditionals, loops, methods, classes, ArrayList, file I/O, and object-oriented programming.

[Software Demo Video](https://youtu.be/4JdH0hYbghI)

# Development Environment

I developed this software using Visual Studio Code as my code editor and the Java Development Kit (JDK) as my development environment. I used Java to compile and run the program and Git/GitHub for version control and project management.

The software was written in Java. The main libraries used were:

java.util.Scanner for reading user input.
java.util.ArrayList for storing and managing the list of expenses.
java.util.HashMap for grouping expenses by category.
java.io for reading and writing expenses to a file.
